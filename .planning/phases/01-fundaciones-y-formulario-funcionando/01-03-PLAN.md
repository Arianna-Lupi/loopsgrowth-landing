## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| YAML del repo a HTML | El texto de `landing.es.yaml` se renderiza en plantillas Astro |
| navegador del visitante a forms.clickup.com | Iframe de origen cruzado con un enlace de respaldo que abre pestaña nueva |
| `location.hash` a `cta-focus.ts` | Entrada controlada por la URL que decide qué elemento recibe el foco |
| descarga de Chromium y del navegador de pruebas | Playwright descarga un binario del CDN de Microsoft |
